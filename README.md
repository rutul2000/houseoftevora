# House of Tevora — starter core
1. Create a Supabase project, run `supabase/schema.sql` in the SQL editor.
2. Copy `.env.example` to `.env.local` and fill in Supabase and Razorpay (test mode first) keys.
3. `npm install && npm run dev`. For Hostinger: push to a Git repo, deploy as Node.js, and set the same variables as environment variables.
Not yet built: admin dashboard, customer accounts/login UI, wishlist UI, order tracking page, email notifications, filters beyond category and sort, reviews, GST invoices, sitemap/robots.
